# After the needle

Narrated visual for a 16:9 recording. The first screen is the cover. Spacebar advances one scene. R returns to the cover. Click the pens, tablet, chart, or empty slot to advance.

Scenes: cover, weekly pen, Wegovy tablet with a 30-minute wait, Foundayo with ATTAIN-1, dated 2030 forecasts, MariTide not approved, close.

This is not a stock recommendation. Build notes are in `BUILD_NOTE.md`.
